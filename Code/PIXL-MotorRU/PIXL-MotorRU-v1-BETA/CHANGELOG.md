# Changelog

## vRU 0.1.0-dev

- Creada la biblioteca Cargo independiente de Python.
- Añadidos procesamiento estático, raster RGBA, SVG estático y animaciones.
- Añadidos diagnósticos con código, severidad y ubicación.
- Añadidas pruebas de integración contra el corpus neutral existente.
- Añadida CLI básica.
- Añadida GUI raster opcional con ampliación sin interpolación.
- Añadidos estilos de contorno con grosor y posiciones `i`, `c` y `e`.
- Añadido registro extensible de definiciones de error.
- Añadidas regresiones para grupos, colores RGBA, `fill` y argumentos extra.

Esta versión está en desarrollo y no constituye una aprobación final de
MotorRU. MotorRU-Core e integración con Mythree están fuera de alcance.
