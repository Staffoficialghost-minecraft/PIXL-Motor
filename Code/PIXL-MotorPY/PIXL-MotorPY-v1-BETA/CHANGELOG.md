# Changelog

## vPY 0.1.0

- Referencia funcional inicial de PIXL 1.1 y 1.2.
- Raster propio y salida SVG mediante `TIPE(vec)`.
- Frames independientes con duración positiva en milisegundos.
- Diagnósticos extensibles y corpus común inicial.
- `plugin_trust` apartado fuera del proyecto activo.

La versión `vPY` identifica el motor y no la versión del lenguaje PIXL.
